# ShelfRow

**ShelfRow** は、かつて多くのユーザーに愛された macOS 用蔵書管理アプリケーション「**Stackroom**」のコンセプト、資産、および操作性を現代の macOS（SwiftUI / SwiftData）環境へと継承・近代化した、高速かつ軽量な書庫管理ツールを目指して開発しているものです。
今後も、重たくなる機能追加はしない予定です。

### あるもの
 - Stackroomに準拠したインタフェースとファイル操作
 - NASでの運用を前提としたフォルダの一括指定(NAS買い替え時等に便利)
 - Stackroom XML インポート機能と、インポート後の不具合を一括修正する各種機能
 - サムネイル等を含めた一括バックアップ機能

### ないもの
 - ビューアは内蔵していません(お好みのものを使ってください)
 - 昔のiTunes風3ペイン検索も個人的に使っていないので外しました

### 作る予定のもの
 - 設定ファイル等も含め全てNASに置いて、複数端末からのアクセスを許容する仕組み

## 🚀 Stackroom からの移行手順（環境設定 → 保守）

Stackroom で管理していたライブラリ資産（データおよびサムネイル画像）を ShelfRow へ移行・引き継ぎする機能は、画面左下の **⚙️（環境設定）>「保守」** タブに集約されています。

> [!IMPORTANT]
> Stackroom からの移行作業は、アプリ導入時に以下のステップ順に行うことを推奨します。

```
[Stackroom Library.xml] ───(1) XMLライブラリのインポート───► SwiftData データベース
[Stackroom サムネイル]   ───(2) サムネイルの移行─────────► ShelfRow キャッシュ領域
[外付けHDD/NASの移動]    ───(3) ボリューム管理────────────► アクセス権一括復旧
```

### 1. XMLライブラリのインポート (`importXMLLibrary`)
- **操作**: 「保守」タブ > **「XMLライブラリのインポート...」** をクリックし、Stackroom の `Stackroom Library.xml` を選択します。
- **仕様**:
  - 書籍情報、フォルダ階層、スマート本棚の定義、レート評価、未読フラグなどを自動でパースし、ShelfRow のデータベースへ移行・マージします。
  - 旧アプリのバグや古い保存APIに起因する非標準な制御コード（`0x01`〜`0x1F` 等の XML 1.0 違反文字）を自動検知して高速クレンジングするため、エラーなく安全に読み込めます。

### 2. Stackroom サムネイルの移行 (`migrateLegacyThumbnails`)
- **操作**: 「保守」タブ > **「Stackroomサムネイルの移行...」** をクリックし、旧 Stackroom のライブラリフォルダ（`~/Library/Application Support/Stackroom/Stackroom Library/` など）を選択します。
- **仕様**:
  - 旧アプリが生成・蓄積してた表紙サムネイル（`[書籍ID]/thumbnail.jpg`）を、ShelfRow のプライベートキャッシュ領域へ一括物理コピーします。
  - **メリット**: 数万冊のアーカイブ（ZIP）を再解凍・CPU再抽出することなく、数秒〜数十秒で表紙表示が完了します。移行完了後は、旧 Stackroom フォルダを完全に削除しても問題ありません。

### 3. ボリューム管理・アクセス権の再割り当て (`manageVolumes`)
- **操作**: 「保守」タブ > **「ボリューム管理...」** をクリックします。
- **仕様**:
  - 外付けHDDの買い替え、マウントポイント変更、NASのパス変更があった場合、親ボリューム（ドライブ）を再選択することで全書籍のセキュリティスコープ付きブックマーク（Security-Scoped Bookmark）およびアクセス権を一括更新します。

### 4. サムネイルの一括生成 (`repairThumbnails`)
- **操作**: 「保守」タブ > **「サムネイルの一括生成...」** をクリックします。
- **仕様**:
  - サムネイルがまだ無い書籍を検出し、連番ヒューリスティックに基づいて表紙を抽出・生成します。CPU コア数（最大8）まで並列実行します。
  - 生成済みの書籍はスキップするため、中断しても再実行すれば続きから進みます。

### 5. ファイル名からのタイトル・属性補完 (`repairEmptyTitles`)
- **操作**: 「保守」タブ > **「ファイル名からタイトルを補完...」** をクリックします。
- **仕様**:
  - 「カスタマイズ」タブで設定したファイル名解析フォーマット（例: `(ジャンル)[作者]タイトル` や `@author`, `@title` など）に基づき、未入力のタイトル・作者・ジャンル等を一括補完します。

### 6. バックアップとリストア
- **操作**: 「保守」タブ > **「バックアップ」** で有効化し、バックアップ先フォルダを指定します。
- **仕様**:
  - 「今すぐバックアップ」で SwiftData DB、サムネイルキャッシュ、設定 plist を指定フォルダ内の `ShelfRowBackup` へ差分保存します。
  - 「バックアップからリストア」で保存時点の状態へ安全に上書き復元できます。

## ✨ 概要と主な特徴

* **Apple Silicon ネイティブ & 高速描画**: macOS 14 (Sonoma) 以降に最適化。SwiftUI ＋ SwiftData ＋ Metal/GPU 対応の軽量デコーディング。
* **大容量ライブラリ対応**: 2万冊を超える蔵書でも、`NSCache` によるオンデマンド・メモリ制御と遅延読み込みで滑らかなスクロール（60fps）を実現。
* **伝統的な 3 ペインデザイン**: 2010年代の macOS アプリが持っていた快適な視認性と直感的な操作感を再現。
* **外部ビューア専門化**: お気に入りのコミックビューア（EdgeView 等）や動画プレイヤーとシームレスに連携。

## 🛠 基本的な使い方

### 1. 画面構成 (3ペイン)
| ペイン | 主な機能・操作 |
| :--- | :--- |
| **左ペイン (サイドバー)** | 「すべての本」「未読の本」やカスタム本棚、条件指定のスマート本棚を表示。ドラッグ＆ドロップで並び替え可能。下部に `[+]`（本棚追加）と `[⚙️]`（環境設定）ボタンを配置。 |
| **中央ペイン (メイン)** | 書籍の一覧表示（大型グリッド表示／詳細リスト表示）。ソート、リアルタイム検索、未読・種別・レートによるマルチフィルタ。ダブルクリックで外部ビューアを起動。 |
| **右ペイン (インスペクター)** | 選択した書籍の詳細情報（タイトル・作者・ジャンル・レート・メモ等）の即時編集、表紙プレビュー、タグ検索チップ、Finder表示。 |

### 2. 書籍の新規登録 (ドラッグ & ドロップ)
- ZIPファイルや画像フォルダを中央ペインへ直接ドラッグ＆ドロップすると、環境設定のファイル名解析規則に従ってタイトル・作者・ジャンル等を自動判定してライブラリへ登録します。

### 3. スマート本棚の作成・編集
- サイドバー下部の `[+]` からスマート本棚を作成できます。
- 作者、ジャンル、キーワード、登録日、レート、未読条件を組み合わせて動的に書籍を自動収集します。

### 4. 外部ビューアの設定
- **⚙️ 環境設定 >「ビューア」**: スライドショーヘルパー（画像フォルダ用）や Zip アーカイブヘルパーを設定。
- **⚙️ 環境設定 >「ヘルパー」**: 拡張子（.cbz, .mov, .rar 等）ごとに割り当てるアプリケーションを指定。
